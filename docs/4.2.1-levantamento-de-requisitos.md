# 4.2.1 Levantamento de Requisitos
## 1. Como os requisitos foram levantados
Os requisitos foram levantados a partir da análise do objetivo do sistema e das necessidades relacionadas à consulta de jogos de corrida de diferentes consoles e épocas.  A conversa com o cliente ainda precisa confirmar quais informações são mais importantes e quais formas de pesquisa devem estar disponíveis.

## 2. Da fala à necessidade
Nº	Fala	Necessidade
- F1  “Quero encontrar jogos de corrida de diferentes consoles.” — usuário	Pesquisar jogos de corrida por console.
- F2  “Quero conhecer jogos de corrida de épocas diferentes.” — usuário	Consultar jogos de diferentes épocas.
- F3  “Quero saber as informações básicas de cada jogo.” — usuário	Consultar informações básicas dos jogos.

## 3. Histórias de usuário
- ID  História de usuário	Veio de
- H1  Como usuário, quero pesquisar jogos de corrida, para encontrar títulos de meu interesse.	F1
- H2  Como usuário, quero consultar jogos de diferentes consoles, para conhecer títulos de outras plataformas.	F1
- H3	Como usuário, quero consultar jogos de diferentes épocas, para conhecer a evolução dos jogos de corrida.	F2
- H4	Como usuário, quero consultar as informações básicas de um jogo, para conhecer melhor o título.	F3

## 4. Requisitos funcionais
ID	Nome	Requisito	Veio de
- RF01	Pesquisar jogos	O sistema deve pesquisar jogos de corrida.	H1 / F1
- RF02	Listar jogos	O sistema deve listar jogos de corrida cadastrados.	H1
- RF03	Filtrar por console	O sistema deve filtrar jogos por console.	H2 / F1
- RF04	Filtrar por época	O sistema deve filtrar jogos por época de lançamento.	H3 / F2
- RF05	Consultar jogo	O sistema deve apresentar informações básicas de um jogo.	H4 / F3

## 5. Requisitos não funcionais
ID	Categoria	Requisito
- RNF01	Usabilidade	 O sistema deve apresentar as informações dos jogos de forma clara e compreensível.
- RNF02	Compatibilidade	 O sistema deve funcionar corretamente em computadores e dispositivos móveis.
- RNF03	Desempenho	 O sistema deve apresentar os resultados das consultas em tempo adequado.

## 6. Conferência com a 4.1
Item do escopo	Requisito que atende
Exibir jogos de corrida de diferentes consoles	RF02, RF03
Exibir jogos de diferentes épocas	RF02, RF04
Apresentar informações básicas dos jogos	RF05
Permitir pesquisa de jogos	RF01

Conferência nos dois sentidos
Toda história tem requisito?
Sim. H1 é atendida por RF01 e RF02, H2 por RF03, H3 por RF04 e H4 por RF05.

Todo requisito tem origem?
Sim. Todos os requisitos funcionais possuem origem em uma história ou fala. Os requisitos não funcionais ainda precisam ser confirmados com o cliente.

O que precisa ser confirmado?
As falas F1, F2 e F3 devem ser substituídas pelas falas reais do cliente. Os requisitos não funcionais também precisam ser confirmados.
