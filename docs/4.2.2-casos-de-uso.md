Não foram utilizadas relações «include» ou «extend».

Especificação do caso de uso principal
O caso de uso principal é Visualizar jogos, pois permite que os visitantes conheçam os jogos de corrida disponíveis no catálogo do GamesRetro.


Campo	
Caso de uso	Visualizar jogos
Ator	Visitante
Pré-condição	O sistema deve estar disponível para acesso.
Pós-condição	A lista de jogos cadastrados é apresentada ao visitante.
Fluxo principal

O visitante acessa o sistema GamesRetro.
O sistema consulta o catálogo de jogos.
O sistema organiza os jogos cadastrados.
O sistema apresenta a lista de jogos disponíveis.
O visitante visualiza os jogos apresentados.
Fluxo alternativo

A1, no passo 3: não existem jogos cadastrados. O sistema informa que não há jogos disponíveis no catálogo e apresenta a lista vazia.
Fluxos de exceção

E1, no passo 2: ocorre uma falha na consulta ao catálogo. O sistema informa que não foi possível carregar os jogos e encerra a operação sem apresentar a lista.
